# Projetos de Análise de Dados — PrograMaria

Repositório com os projetos práticos desenvolvidos durante o curso de Análise de Dados da PrograMaria, aplicando todo o pipeline de análise: exploração e tratamento de dados em Python, consultas e modelagem em SQL, e criação de visualizações para comunicar resultados.

Embora usem ferramentas diferentes, os três projetos giram em torno de um mesmo eixo temático: diversidade e representatividade (gênero, raça e região) — seja no mercado de trabalho em TI, no próprio curso da PrograMaria ou em dados públicos do Brasil.

🛠️ **Tecnologias utilizadas:**

**Python:** Pandas, NumPy, SciPy (Jupyter Notebook / Google Colab);

**SQL:** SQLite e DBeaver;

**Visualização:** Matplotlib, Seaborn, Plotly, Looker Studio.

📁 Projetos:

1. Análise Exploratória de Dados em Python — Mercado de Trabalho em TI

Análise exploratória sobre o mercado de trabalho em Tecnologia da Informação, com Pandas, NumPy e SciPy. Investiga faixa salarial, nível de escolaridade e tecnologias mais utilizadas no setor, com destaque para a representatividade de gênero e raça entre os profissionais de TI.

2. Consultas SQL — Status Brasil (Municípios)

Modelagem de banco de dados relacional e consultas SQL (SQLite/DBeaver) sobre municípios brasileiros, criação, inserção de informações e adicionando colunas nas tabelas, fazendo consultas cruzando dados geográficos, indicadores socioeconômicos (IDHM, educação, renda) e composição racial por região — incluindo a comparação entre pessoas brancas e pretas/pardas em cargos de gerência.

3. Relatório de Análise de Diversidade 2022 — Curso PrograMaria

Relatório em Looker Studio com o perfil de diversidade das 4.271 participantes do curso de Dados da PrograMaria em 2022: recorte por gênero, etnia, PCD e distribuição geográfica pelo Brasil.

📌 Sobre

Projeto desenvolvido durante o curso de Análise de Dados da PrograMaria, com foco em aplicar na prática o ciclo completo de trabalho com dados: coleta/tratamento → consulta/modelagem → visualização → comunicação de resultados.
